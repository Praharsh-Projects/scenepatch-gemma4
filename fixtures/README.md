# Fixture boundary

The app's canvas-generated desk scenes are reproducible developer fixtures, not
release evidence and not a substitute for the entrant's owned hero media.

Place unapproved photographs, voice clips, and recordings under `private/`.
That directory is ignored by Git. Copy an asset into a public fixture set only
after the human rights record in `docs/FIXTURE_RIGHTS.md` contains its exact
filename, SHA-256 hash, completed declarations, and signed approval.
